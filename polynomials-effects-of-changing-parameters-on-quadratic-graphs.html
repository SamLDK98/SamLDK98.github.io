The Effects of Changing Parameters on Quadratic Graphs

One curve. One change at a time.

Start with a square

Squaring a number gives its height on the curve. Move x to explore.

Opposite inputs, equal heights. The turning point is (0, 0).

Add a constant

Add c to every output.

Positive c moves the curve up; negative c moves it down.

Multiply the square

Multiply every output by a.

Larger |a| makes the curve narrower. Negative a turns it upside down.

Add a linear term

Add bx. Watch the turning point.

The shape stays the same. The vertex moves, while (0, 0) stays on the curve.

Bring them together

Change a, b and c, one at a time.

a sets the opening and width; a and b set the horizontal position; c sets the y-intercept.

Control the vertex directly

Write the same curve as a(x − h)² + k.

The vertex is (h, k). Move it with h and k; reshape the curve with a.
