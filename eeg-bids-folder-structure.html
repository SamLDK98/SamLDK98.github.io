BIDS Folder Structure

What BIDS Is

The Brain Imaging Data Structure (BIDS) is a standard for naming and arranging neuroimaging files. If a dataset follows it, anyone, and any BIDS-aware tool, can find every file without being told where it is.

The Top Level

  • dataset_description.json and README are required.
  • Raw data go in the sub- folders. Processed data go in derivatives/. The two are never mixed.
  • sourcedata/ holds files before conversion to BIDS, such as the files copied off the recording computer.

One Participant

  • Leave out ses- folders if each participant was recorded once. If any participant has more than one session, use them for everyone.
  • _eeg.json is required. It must give the task name, reference, sampling rate, mains frequency and software filters.
  • _channels.tsv is recommended. _electrodes.tsv is optional, but if it is there, _coordsystem.json is required.
  • For EDF or EEGLAB data, the three BrainVision files are replaced by one .edf, or a .set and .fdt.

File Names

  • A name is a chain of key-value pairs. A hyphen joins each key to its value, and underscores separate the pairs.
  • The order is fixed: sub, ses, task, acq, run. Only sub and task are always needed.
  • Values can only contain letters and numbers. task-rest_EC breaks the name; use task-restEC.
  • Every file from one recording starts the same way. Only the suffix and extension change.

Derivatives

  • Each pipeline gets its own folder inside derivatives/, with the same sub-, ses- and eeg/ folders below it.
  • Each pipeline folder needs its own dataset_description.json, including a GeneratedBy field naming the software that made it.
  • A processed file keeps the raw file’s name and adds a desc- label before the suffix, saying what was done.
  • Raw files are never overwritten.

Checking a Dataset

  • The BIDS Validator checks a dataset in the browser and lists anything that breaks the rules.
  • MNE-BIDS (Python) and the EEG-BIDS plugin for EEGLAB can write a BIDS dataset, including the sidecar files, from the original recordings.
