Multiple Solutions in an Equation with Only One Unknown?

Quadratic equations can feel confusing if you are used to thinking of equations with one unknown as having only one possible solution.

If an equation has two unknowns, the possible values for either \(x\) or \(y\) are infinite.

Whatever value \(x\) is set to, \(y\) can be set to the value that balances the equation.

\[3x+2y=5\]

However, in an equation with one unknown in the first degree, there is only one value that \(x\) can be.

\[3x-1=5\]

So \(x^2-5x=6\), which has one unknown but two possible solutions (\(-1\) and \(6\)), feels counterintuitive.

To understand where this second solution comes from, let's build up from the simplest equations.

Univariate Linear Expressions

Any equation that can be expressed in terms of constants has only one solution.

\(x=9\) → Already solved.

\(x+3=9\) → Says that \(x\) is \(3\) less than \(9\). There is only one number that is \(3\) less than \(9\).

\(x=\frac{4(13-9)+2}{2.735}\) → There is only one number that is the result of these arithmetic operations.

Any equation that can be expressed as the addition of copies of \(x\) values has only a single solution.

\(x+x=9\) → Says that two copies of \(x\) make \(9\).

\(x\) must be \(4.5\) because there is no other number that two copies of make \(9\).

\[x+x+x=9\]

\(x\) must be \(3\) because there is no other number that three copies of make \(9\).

For all these expressions, as \(x\) increases, every copy of \(x\) increases, so the total only ever moves in one direction. It therefore can only pass each value once.

This type of growth is known as linear, and expressions of the form \(ax+b\) are called linear expressions.

A Constant Times an Unknown (\(Ax\))

If an expression simplifies to a constant times an unknown, we can express the output as the sum of \(x\) values, and it therefore has only one solution.

\[\begin{aligned} 4x=9\ &\rightarrow\ x+x+x+x=9\\ 2x+x=9\ &\rightarrow\ 3x=9\ \rightarrow\ (x+x)+x=9\ \rightarrow\ x+x+x=9\\ 3\cdot2x=9\ &\rightarrow\ 6x=9\ \rightarrow\ x+x+x+x+x+x=9 \end{aligned}\]

In other words, the multiplication of an unknown by a constant still produces a linear expression.

However, unlike addition, where we can add copies of \(x\) together, we cannot multiply copies of \(x\) together.

To appreciate why, let's consider the differences in how multiplication and addition behave.

The Difference between Multiplication and Repeated Addition

Multiplication is often introduced as repeated addition. However, addition and multiplication can behave differently.

When adding two numbers, there is no interaction between their signs, per se.

  • \((+)+(+)=(+)\)
  • \((-)+(-)=(-)\)
  • \((+)+(-)=\) the number with the greater absolute magnitude's sign.

However, when we multiply two numbers, the signs themselves can determine the sign of the output.

  • \((+)\cdot(+)=(+)\)
  • \((-)\cdot(-)=(+)\)
  • \((+)\cdot(-)=(-)\)

There are two behavioural changes:

  • Multiplying by a negative of any magnitude changes the sign of the output.
  • Multiplying two negatives results in a positive output.

In linear expressions the constant and output are known.

Imagine:

\[3x=9\]

The constant and output are both positive. Therefore the unknown must be positive.

However, if we allow multiplication by the unknown on the unknown, things fundamentally change. Knowing the sign of the output no longer enables the unique determination of the unknown.

An Unknown Times an Unknown (\(x^2\))

If we had an equation like:

\[-2x=8\]

While the output \(8\) can be produced by:

\[-2\cdot-4\qquad\text{or}\qquad2\cdot4\]

We already know that one of these numbers must be \((-2)\) so there is only one possible solution for \(x\).

So:

Multiplying an unknown value by a known constant still lets the output uniquely determine the unknown.

If we know the output and the factor multiplying the unknown, we can work out what number the unknown must be.

However, the possible inputs for a multiplication involving unknowns are fundamentally different from the possible inputs for an addition of unknowns.

Let's take a basic example to illustrate:

\[\text{E1: }x+x=9\qquad\text{E2: }x\cdot x=9\]

There is only one possible value for \(x\) in E1.

Yet there are two possible values for \(x\) in E2.

\(9\) could be the output of:

\[3\cdot3\qquad\text{or}\qquad-3\cdot-3\]

But \(x^2-5x=6\) has solutions \(-1\) and \(6\) which aren't just opposites.

An \(x^2\) term allows pairs of additive inverses to be solutions to an equation; however, to understand how possible solutions can differ in magnitude not just sign, we need to consider what happens when we have a first degree and second degree term in an equation.

Univariate Quadratic Expressions

Take:

\[x^2-5x=-6\]

The same \(x\) is involved in two separate terms.

For a given \(x\), the output is the difference between \(x^2\) and \(5x\).

We can rearrange it for a clearer interpretation:

\[5x-x^2=6\]

We could rearrange the equation to make it slightly easier to interpret.

\[a-b=6\]

Solutions for \(x\) are those that make the difference between \(5x\) and \(x^2\) equal to \(6\).

If we think about the terms growing as \(x\) increases, we can look for any moments when \(5x\) is exactly \(6\) ahead of \(x^2\).

Falling, then rising. Anything that falls and then rises can pass the same level twice: once on the way down, once on the way up.

\(x^2-5x\) passes \(-6\) at \(x=2\) on the way down, and again at \(x=3\) on the way up.

The lead of \(5x\) over \(x^2\) can also be drawn as an area. Picture \(5x\) as a strip, \(x\) tall and \(5\) wide, and \(x^2\) as a square, \(x\) by \(x\). Set the square inside the strip. What is left over is \(x\) tall and \(5-x\) wide, and its area is \(5x-x^2\).

As \(x\) grows, the leftover gets taller but narrower. Its area rises, then falls. At \(x=2\) it is \(2\) tall and \(3\) wide; at \(x=3\) it is \(3\) tall and \(2\) wide. It is the same rectangle stood on its side, and both have area \(6\).
