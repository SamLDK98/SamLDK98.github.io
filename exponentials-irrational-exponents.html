Irrational Exponents

Filling the Gaps

We now know what \(2^x\) means when \(x\) is a whole number, zero, a negative integer, or a fraction.

With whole-number exponents, the points are spread out: each step of \(1\) doubles the value.

Halving the step fills the gaps. Each half step multiplies by \(\sqrt{2}\approx1.414\), so each new point sits a little below the straight line between its neighbours.

Each time we halve the step again, the new points fill the gaps, and they line up along a smooth curve.

Between the Fractions

Some numbers are not fractions. \(\sqrt{2}=1.41421\ldots\) cannot be written as \(\frac{m}{n}\), so the root rule gives no meaning to \(2^{\sqrt{2}}\).

But \(\sqrt{2}\) lies between fractions as close to it as we like. Larger exponents give larger powers of \(2\), since each step up multiplies by a factor greater than \(1\). So \(2^{\sqrt{2}}\) must lie between their powers:

BelowAbove
\(2^{1.4}\approx2.639\)\(2^{1.5}\approx2.828\)
\(2^{1.41}\approx2.657\)\(2^{1.42}\approx2.676\)
\(2^{1.414}\approx2.6647\)\(2^{1.415}\approx2.6666\)
\(2^{1.4142}\approx2.66512\)\(2^{1.4143}\approx2.66530\)

The two columns close in on a single number. That number is what we mean by \(2^{\sqrt{2}}\):

\[2^{\sqrt{2}}=2.66514\ldots\]

The Exponential Function

The same squeeze works for any irrational exponent, such as \(2^{\pi}\). So \(2^x\) now has exactly one value for every real number \(x\): it is a function of its exponent.

\[f(x)=2^x\]

This is an exponential function. Its input is the exponent, and its base, \(2\), stays fixed.

On the first page, the exponent began by counting copies, so only counting numbers made sense as inputs. The function's domain has now grown to every real number.

Every output is positive. Each step to the left halves the value, so the curve gets closer and closer to \(0\) but never reaches it.

Any positive base can be squeezed in the same way, so \(a^x\) has a value for every real \(x\) whenever \(a>0\).
