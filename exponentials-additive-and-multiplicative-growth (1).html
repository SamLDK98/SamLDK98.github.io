Exponentials

Additive and Multiplicative Growth

Introduction

Understanding the difference between additive and multiplicative growth is a key prerequisite for understanding exponentiation.

In additive growth, each step adds the same amount to the current output.

In multiplicative growth, each step multiplies the current output by the same factor.

Steps

Imagine travelling from \(0\) to \(256\), passing through all the intermediate values.

Let's think of this continuous journey as being divided into discrete steps.

For an additive journey, each step must cover the same distance along the number line.

We will call the distance covered by each step (i.e. the change in the output produced by one step) the step size.

We can divide the journey into as many steps as we wish, provided we adjust the step size accordingly.

But how exactly must the step size change as we increase or decrease the number of steps?

Let's represent the step size as \(\class{mjx-base}{x}\) and the number of steps as \(\class{mjx-exp}{n}\).

Because each step covers the same distance on the number line:

\[\class{mjx-base}{x} + \class{mjx-base}{x} + \class{mjx-base}{x} + \class{mjx-base}{x} = \class{mjx-exp}{4}\class{mjx-base}{x}\]

The total distance covered is the number of steps taken multiplied by the step size:

\[\class{mjx-exp}{n}\class{mjx-base}{x} = \class{mjx-target}{256}\]

We can rearrange this equation to express the step size in terms of the number of steps:

\[\class{mjx-base}{x} = \frac{\class{mjx-target}{256}}{\class{mjx-exp}{n}}\]

The step size is inversely proportional to the number of steps.

As the number of steps increases by a given factor (\(k\)), the step size decreases by the same factor (\(\frac{1}{k}\)).

For example, if \(\class{mjx-exp}{n}\) is doubled, \(\class{mjx-base}{x}\) is halved.

\[2\class{mjx-exp}{n} \mapsto \frac{\class{mjx-base}{x}}{2}\]
\[k\class{mjx-exp}{n} \mapsto \frac{\class{mjx-base}{x}}{k}\]

For a multiplicative journey, each step must cover a distance that is some factor greater than the previous output.

We will call the factor each step multiplies the current output by the step ratio or the multiplicative factor.

But how exactly must the step ratio change as we increase or decrease the number of steps?

Let's represent the step ratio as \(\class{mjx-base}{r}\) and the number of steps as \(\class{mjx-exp}{n}\).

Because each step multiplies by the same factor:

\[\class{mjx-base}{r} \cdot \class{mjx-base}{r} \cdot \class{mjx-base}{r} \cdot \class{mjx-base}{r} \cdot \class{mjx-base}{r} = \class{mjx-base}{r}^{\class{mjx-exp}{5}}\]

The total distance covered is the step ratio multiplied by itself as many times as the number of steps:

\[\class{mjx-base}{r}^{\class{mjx-exp}{n}} = \class{mjx-target}{256}\]

We can rearrange this to express the step ratio in terms of the number of steps:

\[\class{mjx-base}{r} = \class{mjx-target}{256}^{1/\class{mjx-exp}{n}}\]

As the number of steps increases by a given factor (\(k\)), the step ratio decreases by becoming its \(k^{\text{th}}\) root.

For example, if \(\class{mjx-exp}{n}\) is doubled, \(\class{mjx-base}{r}\) becomes \(\sqrt{\class{mjx-base}{r}}\).

\[2\class{mjx-exp}{n} \mapsto \sqrt{\class{mjx-base}{r}}\]
\[k\class{mjx-exp}{n} \mapsto \sqrt[k]{\class{mjx-base}{r}}\]

Steps and Output

Having divided our journey into discrete steps, there are two quantities we can track as we progress:

  1. Portion of steps taken
  2. Portion of target output reached

For additive growth, the relationship between the two is directly proportional.

If we have taken \(x\%\) of our total steps, then we have reached \(x\%\) of our target output.

While the additive growth journey increases at a constant rate, the rate at which the multiplicative journey increases the output increases the more we progress in our steps.

On an ordinary number line, equal distances represent equal differences between values.

But we can construct a different type of number line, where equal distances represent equal ratios between values.

This is called a logarithmic scale.

On a logarithmic number line, the distance between \(1\) and \(10\) is the same as the distance between \(10\) and \(100\), because the ratio between both is the same: \(\class{mjx-base}{\times 10}\).
