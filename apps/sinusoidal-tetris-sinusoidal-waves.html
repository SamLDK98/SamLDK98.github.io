Sinusoidal Waves

Imagine a point travelling around a circle at a constant speed.

If we plot its height on the \(y\)-axis and time on the \(x\)-axis, we graph a sinusoidal wave.

Three parameters of this circular motion can vary:

  • The speed at which the point travels around the circle.
  • The size of the circle (its radius).
  • The position the point starts from.

Each one sets a property of the resulting wave:

  • Frequency \((f)\): the number of complete oscillations (cycles) per second.
  • Amplitude \((A)\): the greatest height of the peaks, and depth of the troughs, measured from the centre line.
  • Initial phase \((\phi)\): where the wave starts, both its height on the \(y\)-axis and the direction it is moving in. Two waves can start at the same height, one rising and the other falling.

Measuring the Speed of Rotation

We usually measure speed as distance travelled per unit of time, \(\frac{\text{distance}}{\text{time}}\).

Here, though, we measure the number of complete rotations the point makes per second, not the distance it covers along the circumference.

This keeps the parameter that sets the frequency independent of the radius.

Suppose circle A has twice the radius of circle B. If a point travels around each at the same speed in distance per second, it takes twice as long to complete a rotation of the larger circle, so the larger circle produces a wave of half the frequency.

Measuring speed as the rate of rotation avoids this. If we fix the rate of rotation and change only the size of the circle, the frequency stays the same; only the amplitude changes.

The rate of rotation can be given in two ways.

The frequency \(f\) counts complete rotations per second. The angular frequency \(\omega\) instead measures the angle the point sweeps through per second, in radians.

One complete rotation is an angle of \(2\pi\) radians, so the two differ only by that factor:

\[\omega = 2\pi f\]

A point making one rotation per second has \(f = 1\) and \(\omega = 2\pi \approx 6.28\) radians per second. At two rotations per second, \(f = 2\) and \(\omega = 4\pi\).

Both describe the same motion. Frequency is easier to picture; angular frequency is more convenient in formulas, because the angle the point has turned through after \(t\) seconds is simply \(\omega t\). That is why a sinusoidal wave is usually written as

\[y = A \sin(\omega t + \phi) = A \sin(2\pi f t + \phi)\]
