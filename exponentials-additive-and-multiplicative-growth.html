Exponentials

Additive and Multiplicative Growth

Understanding the difference between additive and multiplicative growth is a key prerequisite for understanding exponentiation.

In additive growth, each step adds the same amount to the current output.

In multiplicative growth, each step multiplies the current output by the same factor.

Growing by a constant factor of \(\class{mjx-base}{4}\)

The number of cells in the grid represents the factor we are growing by. Although the absolute increase from one square to the next varies, the next square is always \(4\) times as big.

Progress in Additive Journeys

Imagine travelling from \(0\) to \(256\), passing through all the intermediate values.

Let's think of this continuous journey as being divided into discrete steps.

For an additive journey, the distance (i.e. the change in output) covered by each step must be equal.

We can divide the journey into as many or as few steps as we wish, as long as we adjust the step size accordingly.

Division can find the number of steps needed to reach a target output for a given step size.

Division can find the step size needed to reach a target output for a given number of steps.

\[\frac{\text{target output}}{\text{step size}} = \text{total steps}\]
\[\frac{\text{target output}}{\text{total steps}} = \text{step size}\]

How Additive Changes Accumulate

The difference between successive outputs is always the same in additive growth, regardless of where we are in the journey.

Further, the difference between \(x\) number of successive steps is always the same. The change accumulates through addition; for example, if one step adds \(6\) to the output, then \(3\) steps will add \(6 + 6 + 6 = 18\), regardless of where we are in the journey.

The Relationship Between Additive Steps and Output

We can track two quantities as we progress in our growth journey:

  • Steps taken
  • Output

Because every step adds the same amount, the percentage of steps taken always equals the percentage of the target output reached, however we divide the journey.

\[\text{total steps }\% = \text{target output }\%\]

Reconstructing the Total from Partial Progress

Because:

\[\text{steps complete }\% = \text{target output }\%\]

Calculating the target output when we know the output reached after a given percentage of steps is straightforward.

  1. Work out how many times that percentage needs to be added to itself to reach \(100\%\).

    For \(25\%\), \(40\%\), and \(85\%\):

    \[\frac{100}{25} = 4, \qquad \frac{100}{40} = 2.5, \qquad \frac{100}{85} \approx 1.17\]

  2. This will correspond to the number of times we need to add the current output (\(x\)) to itself to reach the target output.

    For \(25\%\):

    \[x + x + x + x = 4x\]

    For \(40\%\):

    \[x + x + 0.5x = 2.5x\]

    For \(85\%\):

    \[x + 0.17647x \approx 1.17647x\]

Progress in Multiplicative Journeys

Multiplicative journeys start at \(1\) instead of \(0\).

This time we progress by multiplying the current output by a constant factor.

\[1 \xrightarrow{\times 2} 2 \xrightarrow{\times 2} 4 \xrightarrow{\times 2} 8 \xrightarrow{\times 2} 16 \xrightarrow{\times 2} 32 \xrightarrow{\times 2} 64 \xrightarrow{\times 2} 128 \xrightarrow{\times 2} 256\]

How Multiplicative Changes Accumulate

The change in output covered by each step is no longer equal. Consequently, neither are the differences between successive outputs.

However, the ratios between successive outputs are equal.

Recall that in additive growth, the changes produced by successive steps accumulate through addition. For example, three steps of \(+6\) produce a total increase of:

\[6 + 6 + 6 = 18\]

In multiplicative growth, the factors combine through multiplication.

Three steps of \(\times 2\) produce a total factor of:

\[2 \times 2 \times 2 = 8\]

Drag the white dots to select more steps, then use the arrows to slide them along the line. Each extra step multiplies the ratio by \(2\), but for a given number of steps, the ratio is the same wherever they sit.

Equal numbers of multiplicative steps produce equal ratios between outputs, regardless of where they occur along the journey.

The Relationship Between Multiplicative Steps and Output

When each step changes the output by a constant factor:

\[\text{steps taken }\% \ne \text{target output }\%\]

Previously, we used division to identify the number of steps needed to reach our target output given a constant step size.

Now, we will use logarithms to identify the number of steps needed to reach our target output given a constant step ratio (we will discuss this operation in more detail later).

Target: \(256\)
Step size ratio: \(\times\class{mjx-base}{2}\)

\[\log_{2}(256) = 8\]

Number of steps in the journey from \(1 \to 256\): \(8\).

\[1 \to 2 \to 4 \to 8 \to 16 \to 32 \to 64 \to 128 \to 256\]

Let's examine the relationship between the percentage of steps completed and the percentage of the target output reached.

% of Steps Taken% of Output ReachedOutput
\(25\%\)\(\approx 1.56\%\)\(4\)
\(40\%\)\(\approx 3.59\%\)\(\approx 9.19\)
\(50\%\)\(6.25\%\)\(16\)
\(85\%\)\(\approx 43.53\%\)\(\approx 111.43\)
\(100\%\)\(100\%\)\(256\)

Recall that, in additive growth, equal portions of a journey contribute equal increases in output. For example, completing \(25\%\) of the steps in a journey from \(0\) to \(200\) produces an output of \(50\).

Because four groups of \(25\%\) make up the complete journey, we can add the accumulated increase four times:

\[50 + 50 + 50 + 50 = 200\]

In multiplicative growth, equal portions of a journey contribute equal multiplicative factors instead.

After completing \(25\%\) of our steps, we have reached \(4\).

That is an increase of \(\times 4\) from our starting output \(1\).

Each subsequent \(25\%\) of the journey must then multiply the current output by that same factor of \(4\):

\[1 \xrightarrow{\times 4} 4 \xrightarrow{\times 4} 16 \xrightarrow{\times 4} 64 \xrightarrow{\times 4} 256\]

Therefore:

\[4 \times 4 \times 4 \times 4 = 256\]

Because four groups of \(25\%\) make up the complete journey:

\[\frac{100}{25} = 4\]

We can express the repeated multiplication using an exponent:

\[4^4 = \boxed{256}\]

If we took \(50\%\) of our steps, we calculate how many groups of \(50\%\) make up the journey:

\[\frac{100}{50} = 2\]

The output after \(50\%\) is \(16\).

So to reach \(100\%\) we must multiply this value by itself \(2\) times:

\[16 \times 16\]
\[16^2\]
\[16 \times 16 = 256\]

Taking \(\frac{1}{2}\) our steps means we can multiply the value there by itself to reach the output because the ratio between the start and the halfway point must be the same as the ratio between the halfway point and the final target output.

What about \(40\%\)?

\[\frac{100}{40} = 2.5\]

Our multiplicative factor has accumulated \(2.5\) times.

\[\approx 9.19^{2.5}\]

Finally, consider \(85\%\) (\(\frac{17}{20}\)) of steps complete.

\[\frac{100}{85} = 1.17647059\]
\[111.43^{1.17647059}\]

The difference is that with additive growth, we multiply; with multiplicative growth, we exponentiate.

Suppose we have completed \(25\%\) of our steps and reached an output of \(x\).

In an additive journey starting at \(0\), the increases accumulate through addition:

\[x + x + x + x = \text{Target output}\]

Which we can express as multiplication:

\[\boxed{4x = \text{Target output}}\]

In a multiplicative journey starting at \(1\), the factors accumulate through multiplication:

\[x \cdot x \cdot x \cdot x = \text{Target output}\]

Which we can express as exponentiation:

\[\boxed{x^4 = \text{Target output}}\]
