Exponentials

Additive and Multiplicative Growth

In additive growth, each step adds the same amount to the current output.

In multiplicative growth, each step multiplies the current output by the same factor.

Steps

Imagine travelling from \(0\) to \(256\), passing through all the intermediate values.

Let's think of this continuous journey as being divided into discrete steps.

Additive Steps

For an additive journey, each step must cover the same distance along the number line.

We will call the distance covered by each step (i.e. the change in the output produced by one step) the step size.

We can divide the journey into as many steps as we wish, provided we adjust the step size .

How does the step size depend on the number of steps?

Let's represent the number of steps as \(n\) and the step size as \(d\) (for common difference).

\(T\) will stand for the total change in the output.

\[T = \text{final output} - \text{starting output}\]

Since each step contributes the same change, \(n\) steps produce a total change of \(nd\).

\[nd = T\]

Rearranged to express the step size in terms of the number of steps or vice versa:

\[d = \frac{T}{n}, \qquad n = \frac{T}{d}\]

These expressions describe an inverse proportional relationship between \(n\) and \(d\).

For a fixed \(T\), multiplying either variable by a factor of \(k\) requires dividing the other by \(k\).

For example, if the number of steps increases by a factor of \(2\), the step size will decrease by a factor of \(2\).

\[n \mapsto kn \implies d \mapsto \frac{d}{k}\]

Say we start at \(0\) and end at \(256\).

\[0 + nd = 256\]

If \(n = 4\):

\[0 + d + d + d + d = 256\]
\[4d = 256\]
\[d = \frac{256}{4}\]
\[d = 64\]

What do you think happens to the step size if we increase \(n\) by \(1\)?

If \(n = 5\):

\[5d = 256\]
\[d = \frac{256}{5}\]
\[d = 51.2\]

Increasing \(n\) decreases \(d\).

What do you think happens to the step size if we double \(n\)?

If \(n = 8\):

\[8d = 256\]
\[d = \frac{256}{8}\]
\[d = 32\]

Increasing \(n\) by a factor of \(2\) decreases \(d\) by a factor of \(2\).

What happens if \(n = 4\) but we start and end our journey at different points?

If we start at \(16\) and end at \(128\):

\[16 + nd = 128\]

If \(n = 4\):

\[16 + d + d + d + d = 128\]
\[16 + 4d = 128\]
\[4d = 112\]
\[d = 28\]

The total change is the difference between the starting and final outputs. Once we know this difference, we can calculate the step size in exactly the same way.

Multiplicative Steps

Multiplicative growth cannot begin at \(0\) (we couldn't multiply our way out of it!), so let's begin at \(1\).

For a multiplicative journey, each step must multiply the current output by the same factor.

We will call the ratio between successive outputs the step ratio.

We can divide the journey into as many steps as we wish, provided we adjust the step ratio .

How does the step ratio depend on the number of steps?

Let's represent the number of steps as \(n\) and the step ratio as \(r\).

\(R\) will stand for the total multiplicative factor between a starting and end point.

\[R = \frac{\text{final output}}{\text{starting output}}\]

Since each step multiplies the current output by the same factor, \(n\) steps produce a combined multiplicative factor of \(r^n\).

\[r^n = R\]

Rearranged to express the step ratio in terms of the number of steps:

\[r = \sqrt[n]{R} = R^{1/n}\]

Or the number of steps in terms of the step ratio:

\[n = \log_r(R)\]

For a fixed \(R\), increasing the number of steps requires decreasing the step ratio.

Multiplying the number of steps by a factor of \(k\) requires taking the \(k\)th root of the step ratio.

For example, doubling the number of steps requires taking the square root of the step ratio.

\[n \mapsto kn \quad \Longrightarrow \quad r \mapsto \sqrt[k]{r}\]

Say we start at \(1\) and end at \(256\).

\[1 \cdot r^n = 256\]

If \(n = 4\):

\[1 \cdot r \cdot r \cdot r \cdot r = 256\]
\[r^4 = 256\]
\[r = \sqrt[4]{256} = 4\]

What do you think happens to the step ratio if we increase \(n\) by \(1\)?

If \(n = 5\):

\[r^5 = 256\]
\[r = \sqrt[5]{256} \approx 3.031\]

Increasing \(n\) decreases \(r\).

What do you think happens to the step ratio if we double \(n\)?

If \(n = 8\):

\[r^8 = 256\]
\[r = \sqrt[8]{256} = 2\]

Doubling \(n\) takes the square root of the original step ratio: \(\sqrt{4} = 2\).

What happens if \(n = 4\) but we start and end our journey at different points?

If we start at \(2\) and end at \(512\):

\[2r^n = 512\]

If \(n = 4\):

\[2r^4 = 512\]
\[r^4 = 256\]
\[r = \sqrt[4]{256} = 4\]

The total multiplicative factor is the ratio between the final and starting outputs. Once we know this ratio, we can calculate the step ratio in exactly the same way.

Visualising the Relationship Between Steps and Output

Having divided our journeys into discrete steps, there are two quantities we can track as we progress:

  1. Proportion of steps completed
  2. Proportion of the target output reached

For additive growth, the relationship is directly proportional.

If we have taken \(x\%\) of our total steps, then we have reached \(x\%\) of our target output.

For multiplicative growth, however, the relationship between the two proportions is not immediately obvious.

The following graphs show the percentage of steps completed on the \(x\)-axis and the corresponding output on the \(y\)-axis.

Notice that halfway through the multiplicative journey, we have reached only \(10\%\) of our target output.

While additive growth produces a constant increase in output per step, multiplicative growth produces increasingly large increases in output as we progress through the journey.

\(y\)-axis linearly scaled

But is there a way of representing output in which equal multiplicative steps correspond to equal distances along the output axis?

On an ordinary number line, equal distances represent equal differences between values.

But we can construct a different type of number line, where equal distances represent equal ratios between values.

This is called a logarithmic scale.

On a logarithmic number line, the distance between \(1\) and \(10\) is the same as the distance between \(10\) and \(100\), because the ratio between both is the same: \(\times 10\).

When we use a logarithmic scale for the \(y\)-axis, the relationship between multiplicative steps and output becomes a straight line.

How Steps Combine

In additive growth, the change in output produced by one step is the same, regardless of where that step occurs along the number line.

The changes produced by successive additive steps combine through addition.

The combined change produced by \(n\) successive steps is the sum of the changes produced by each individual step.

This combined change is the same regardless of where those \(n\) steps occur along the number line.

(Click and drag one of the white dots below to change the number of steps.)

In multiplicative growth, the absolute changes in output are no longer equal. However, the ratio between successive outputs remains constant.

The multiplicative factors applied at successive steps combine through multiplication.

For example, three steps of \(\times 2\) produce a combined multiplicative factor of:

\[2 \times 2 \times 2 = 8\]

Again, move the white dots to change the number of steps and observe how the combined factor changes.

Consequently, equal portions of an additive journey produce equal increases, while equal portions of a multiplicative journey produce equal factors.

For example, each successive \(12.5\%\) portion of a journey produces the same additive change or multiplicative factor, depending on the type of growth.

This is what allows us to calculate the output at any fractional position along a journey.

Calculating Outputs at Fractional Positions

We can describe how far we have progressed through a journey in several ways.

\[\text{a quarter} = \frac{1}{4} = 0.25 = 25\%\]

These are simply different ways of expressing the same proportion of the whole.

We will primarily express progress as a percentage or as a fraction.

Calculating Outputs in Additive Journeys

Because every step adds the same amount, the percentage of steps taken always equals the percentage of the target output reached, however we divide the journey.

\[\text{total steps }\% = \text{target output }\%\]

Calculating Outputs in Multiplicative Journeys

For multiplicative growth, the percentage of steps taken and the percentage of the target output reached is not equivalent.

Suppose our journey starts at \(1\) and ends at \(x\).

If we have taken \(50\%\), \(25\%\), \(3\%\) or \(97\%\) of our steps, what output have we reached?

  • After \(50\%\) or \(\frac{1}{2}\) of our multiplicative steps, what is the corresponding output?

    We partition the journey into two equal portions, each multiplying the output by the same factor, \(r\).

    \[1 \cdot r \cdot r = x\]
    \[r^2 = x\]

    Therefore:

    \[r = \sqrt{x}\]

    For a journey starting at \(1\) and ending at \(x\), the output at \(50\%\) of our total steps taken is \(\sqrt{x}\).

    For example, if we start at \(1\) and our target is \(25\):

    \[1 \cdot r \cdot r = 25\]
    \[r^2 = 25\]
    \[r = \sqrt{25}\]
    \[r = 5\]

    After \(50\%\) of our multiplicative steps, the corresponding output will be \(5\).

  • After \(25\%\) or \(\frac{1}{4}\) of our multiplicative steps, what is the corresponding output?

    We can partition the journey into four equal portions, each multiplying the output by the same factor, \(r\).

    \[1 \cdot r \cdot r \cdot r \cdot r = x\]
    \[r^4 = x\]
    \[r = \sqrt[4]{x}\]

    For a journey starting at \(1\) and ending at \(x\), the output at \(25\%\) of our total steps taken is \(\sqrt[4]{x}\).

    If we start at \(1\) and end at \(512\), the output after \(25\%\) would be:

    \[\sqrt[4]{512} \approx 4.75682846\]

    But what about if we start somewhere other than \(1\)?

    Say we start at \(2\) and our final output is \(512\):

    \[2 \cdot r \cdot r \cdot r \cdot r = 512\]
    \[2r^4 = 512\]
    \[r^4 = \frac{512}{2}\]
    \[r^4 = 256\]
    \[r = \sqrt[4]{256}\]
    \[r = 4\]

    Notice that we divided the final output by the starting output to find the total multiplicative factor, \(R\). This parallels additive growth, where we subtract the starting output from the final output to find the total additive change, \(T\).

    Here, \(r\) denotes the multiplicative factor that will take us to the final output if we start at \(2\) and include \(4\) factors of \(r\).

    Since \(25\%\) of four steps is one step, to find the output we multiply our starting output of \(2\) by \(r\) once.

    The corresponding output is therefore:

    \[2 \cdot 4 = \boxed{8}\]

  • After \(3\%\) or \(\frac{3}{100}\) of our multiplicative steps, what is the corresponding output?

    We can partition the journey into \(100\) equal portions, each multiplying the output by the same factor, \(r\).

    \[r^{100} = x\]
    \[r = \sqrt[100]{x}\]

    This gives us the output at \(1\%\) (assuming we start at \(1\)).

    We need to apply the factor \(r\) three times:

    \[r^3 = \bigl(\,\sqrt[100]{x}\,\bigr)^3\]

    For example, if we start at \(3\) and our target is \(3 \times 2^{100}\):

    \[3r^{100} = 3 \times 2^{100}\]
    \[r^{100} = 2^{100}\]
    \[r = 2\]

    Here, \(r\) is the factor that, raised to the \(100\)th power, gives us the total multiplicative factor that, if applied to the starting output, \(3\), gives us the final output.

    After \(3\%\) of our steps, we have applied this factor three times:

    \[3 \times r^3 = 3 \times 2^3\]
    \[3 \times 8 = \boxed{24}\]

    So we reach an output of \(24\).

  • After \(97\%\) or \(\frac{97}{100}\) of our multiplicative steps, what is the corresponding output?

    We can partition the journey into \(100\) equal portions, each multiplying the output by the same factor, \(r\).

    \[r^{100} = x\]
    \[r = \sqrt[100]{x}\]

    This gives us the output at \(1\%\) (assuming our starting output is \(1\)).

    We need to apply the factor \(r\) \(97\) times:

    \[r^{97} = \bigl(\,\sqrt[100]{x}\,\bigr)^{97}\]

    For example, if we start at \(2\) and our target is \(2 \times 2^{100}\):

    \[2r^{100} = 2 \times 2^{100}\]
    \[r^{100} = 2^{100}\]
    \[r = 2\]

    After \(97\%\) of our steps, we have applied the factor \(r\) \(97\) times to our starting output \(2\):

    \[2 \times r^{97} = 2 \times 2^{97}\]
    \[\boxed{2^{98}}\]

    So we reach an output of \(2^{98}\), approximately \(3.17 \times 10^{29}\).

Calculating outputs at fractional positions involves different operations depending on the type of growth.

Halfway, a quarter, or a sixteenth of the way through an additive journey just corresponds to dividing the whole by the relevant factor.

A sixteenth of \(144\) is just:

\[\frac{144}{16} = 9\]

The same fractions through a multiplicative journey correspond with taking the relevant root of the final output.

A sixteenth of \(144\) is just:

\[\sqrt[16]{144} \approx 1.36\]

Division is to additive journeys what taking roots is to multiplicative journeys.

For non-unit fractions, we also use multiplication with additive journeys and exponentiation with multiplicative journeys to scale the result for one portion up to the number of portions we need.

To identify the output after \(\frac{3}{4}\) of an additive journey starting at \(0\) and ending at \(100\).

We would find \(\frac{1}{4}\) using division and then multiply that by \(3\):

\[3 \cdot \frac{100}{4}\]
\[3 \cdot 25 = 75\]

To identify the output after \(\frac{3}{4}\) of a multiplicative journey starting at \(1\) and ending at \(100\).

We would find \(\frac{1}{4}\) using radication and then raise that to the \(3\)rd power.

\[\bigl(\,\sqrt[4]{100}\,\bigr)^3\]
\[(3.16227766)^3 \approx 31.62\]

Reconstructing the Total from Partial Progress

Because:

\[\text{steps complete }\% = \text{target output }\%\]

Calculating the target output when we know the output reached after a given percentage of steps is straightforward.

  1. Work out how many times that percentage needs to be added to itself to reach \(100\%\).

    For \(25\%\), \(40\%\), and \(85\%\):

    \[\frac{100}{25} = 4, \qquad \frac{100}{40} = 2.5, \qquad \frac{100}{85} \approx 1.17\]

  2. This will correspond to the number of times we need to add the current output (\(x\)) to itself to reach the target output.

    For \(25\%\):

    \[x + x + x + x = 4x\]

    For \(40\%\):

    \[x + x + 0.5x = 2.5x\]

    For \(85\%\):

    \[x + 0.17647x \approx 1.17647x\]

The Relationship Between Multiplicative Steps and Output

When each step changes the output by a constant factor:

\[\text{steps taken }\% \ne \text{target output }\%\]

Previously, we used division to identify the number of steps needed to reach our target output given a constant step size.

Now, we will use logarithms to identify the number of steps needed to reach our target output given a constant step ratio (we will discuss this operation in more detail later).

Target: \(256\)
Step size ratio: \(\times\class{mjx-base}{2}\)

\[\log_{2}(256) = 8\]

Number of steps in the journey from \(1 \to 256\): \(8\).

\[1 \to 2 \to 4 \to 8 \to 16 \to 32 \to 64 \to 128 \to 256\]

Let's examine the relationship between the percentage of steps completed and the percentage of the target output reached.

% of Steps Taken% of Output ReachedOutput
\(25\%\)\(\approx 1.56\%\)\(4\)
\(40\%\)\(\approx 3.59\%\)\(\approx 9.19\)
\(50\%\)\(6.25\%\)\(16\)
\(85\%\)\(\approx 43.53\%\)\(\approx 111.43\)
\(100\%\)\(100\%\)\(256\)

Recall that, in additive growth, equal portions of a journey contribute equal increases in output. For example, completing \(25\%\) of the steps in a journey from \(0\) to \(200\) produces an output of \(50\).

Because four groups of \(25\%\) make up the complete journey, we can add the accumulated increase four times:

\[50 + 50 + 50 + 50 = 200\]

In multiplicative growth, equal portions of a journey contribute equal multiplicative factors instead.

After completing \(25\%\) of our steps, we have reached \(4\).

That is an increase of \(\times 4\) from our starting output \(1\).

Each subsequent \(25\%\) of the journey must then multiply the current output by that same factor of \(4\):

\[1 \xrightarrow{\times 4} 4 \xrightarrow{\times 4} 16 \xrightarrow{\times 4} 64 \xrightarrow{\times 4} 256\]

Therefore:

\[4 \times 4 \times 4 \times 4 = 256\]

Because four groups of \(25\%\) make up the complete journey:

\[\frac{100}{25} = 4\]

We can express the repeated multiplication using an exponent:

\[4^4 = \boxed{256}\]

If we took \(50\%\) of our steps, we calculate how many groups of \(50\%\) make up the journey:

\[\frac{100}{50} = 2\]

The output after \(50\%\) is \(16\).

So to reach \(100\%\) we must multiply this value by itself \(2\) times:

\[16 \times 16\]
\[16^2\]
\[16 \times 16 = 256\]

Taking \(\frac{1}{2}\) our steps means we can multiply the value there by itself to reach the output because the ratio between the start and the halfway point must be the same as the ratio between the halfway point and the final target output.

What about \(40\%\)?

\[\frac{100}{40} = 2.5\]

Our multiplicative factor has accumulated \(2.5\) times.

\[\approx 9.19^{2.5}\]

Finally, consider \(85\%\) (\(\frac{17}{20}\)) of steps complete.

\[\frac{100}{85} = 1.17647059\]
\[111.43^{1.17647059}\]

The difference is that with additive growth, we multiply; with multiplicative growth, we exponentiate.

Suppose we have completed \(25\%\) of our steps and reached an output of \(x\).

In an additive journey starting at \(0\), the increases accumulate through addition:

\[x + x + x + x = \text{Target output}\]

Which we can express as multiplication:

\[\boxed{4x = \text{Target output}}\]

In a multiplicative journey starting at \(1\), the factors accumulate through multiplication:

\[x \cdot x \cdot x \cdot x = \text{Target output}\]

Which we can express as exponentiation:

\[\boxed{x^4 = \text{Target output}}\]
