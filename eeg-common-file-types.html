Common File Types

What Is a Bit?

A bit is the smallest unit a computer stores. It has two states, written 0 and 1.

Grouping bits gives more possible values: a group of n bits can hold 2n different values.

What Is a Byte?

A byte is a group of eight bits, so it can hold 256 different values, from 0 to 255.

Bytes are usually written as two hexadecimal digits, from 00 to FF. Hexadecimal counts in sixteens, using 0–9 and then A–F for 10–15. So 3F is 3 × 16 + 15 = 63.

What Is a File?

A file is a named sequence of bytes stored on a disk.

Formats and Extensions

A format is the set of rules for reading a file’s bytes: where the header ends, what each field means, how many bytes make one sample, and what order the samples are in.

The extension is the end of the filename, after the dot. It tells software which format the file is in, and so which rules to use.

The extension is only a label:

To change format, a file has to be converted: read with one set of rules and written with another.

Some parts of a file are text, which a text editor can read, like a BrainVision header. The samples are almost always binary: compact, but unreadable without the format’s rules.

Reading the Same Bytes Two Ways

A format that stores 16-bit integers reads these bytes as two samples: 0 and 16256. A format that stores 32-bit floats reads them as one sample: 1.0.

Both readings take the last byte of each group as the most significant. This byte order is also part of the format.

Software that applies the wrong rules still produces numbers. They are just wrong.

What Every EEG Format Stores

Every EEG format stores the same three things:

  • Header: channel names, sampling rate, and how to convert stored values to µV.
  • Data: the samples.
  • Events: markers or annotations with their times.

EDF and EDF+

  • One file: a plain-text header, then the data.
  • Values are stored as 16-bit integers. The header gives each channel a physical and a digital minimum and maximum, which convert integers to µV.
  • One integer step is worth (physical range) ÷ (digital range). A ±3,200 µV range gives steps of about 0.1 µV. If the range was set too wide on export, the precision is lost.
  • Each channel can have its own sampling rate. Check they match.
  • EDF+ stores events as an extra channel called EDF Annotations. This channel is a common cause of failed imports. Turning annotations off at import usually fixes it, but the events are then lost.
  • BDF is BioSemi's 24-bit version of EDF. Triggers are in the Status channel.

BrainVision

  • .vhdr: header (text)
  • .eeg: data (binary)
  • .vmrk: markers (text)

Header excerpt:

[Common Infos]
DataFile=sub-01_task-rest_eeg.eeg
MarkerFile=sub-01_task-rest_eeg.vmrk
DataOrientation=MULTIPLEXED
NumberOfChannels=64
SamplingInterval=2000

[Binary Infos]
BinaryFormat=INT_16

[Channel Infos]
Ch1=Fp1,,0.1,µV
...
  • SamplingInterval is in microseconds: 2000 µs = 500 Hz.
  • Channel lines are name, reference, resolution, unit. A blank reference means the online reference.
  • BinaryFormat is INT_16 or IEEE_FLOAT_32.
  • Amplifier settings and impedances are often listed at the bottom of the file.

Marker excerpt:

Mk1=New Segment,,1,1,0,20251116093012000000
Mk2=Stimulus,S  1,5000,1,0
  • Fields are type, description, position, length, channel.
  • Position is in samples, counting from 1. Channel 0 means all channels.

Don't rename the files directly. The .vhdr names the .eeg and .vmrk files, and the .vmrk names the .eeg file. Edit those lines as well, or rename with a tool such as MNE-BIDS.

EEGLAB

  • The .set is a MATLAB file holding the EEG structure. The data are either inside it or in a separate .fdt.
  • A .set refers to its .fdt by name. Rename with Save As in EEGLAB, not on disk.
  • It stores the processing state: channel locations, events, ICA weights and command history. Use it for intermediate steps, and keep the raw recording in its original format.

BIDS

BIDS is a folder and naming convention, not a file format. For EEG it accepts EDF, BrainVision, EEGLAB and BDF, and recommends EDF or BrainVision.

Converting

  • Convert a copy. Keep the original.
  • Compare channel count, sampling rate, duration and number of events before and after.
  • Plot a few seconds of one channel from both files and check they match.
  • Converting to EDF can lose precision, because it stores 16-bit integers.
