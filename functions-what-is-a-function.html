Functions

What is a function?

Inputs and Outputs

Imagine a rule: take a number and add \(3\).

If we start with \(2\), we get \(5\). If we start with \(7\), we get \(10\).

\(2\longrightarrow5\)

\(7\longrightarrow10\)

The number we start with is the input. The number we get is the output.

A function assigns exactly one output to each allowed input.

Function Notation

We can give our function a name, such as \(f\), and write its rule as:

\(f(x)=x+3\)

Here, \(x\) represents the input, and \(f(x)\) represents the output.

We read \(f(x)\) as “f of x”. It means the value of the function \(f\) at the input \(x\).

It does not mean \(f\) multiplied by \(x\).

To find the output for an input of \(2\), we replace \(x\) with \(2\):

\(f(2)=2+3=5\)

The function's name is \(f\); the number inside the parentheses tells us which input we are using.

One Output for Each Input

The same input must always have the same output.

With our rule, an input of \(2\) gives \(5\). It cannot also give \(8\).

However, different inputs can have the same output.

Consider another function:

\(g(x)=x^2\)

\(g(2)=4\qquad\text{and}\qquad g(-2)=4\)

This is still a function. Each input has exactly one output, even though these two inputs share an output.

Which Inputs Are Allowed?

The set of allowed inputs is called the domain.

For \(f(x)=x+3\), we can allow every real number as an input.

But consider:

\(h(x)=\frac{1}{x}\)

We cannot use \(0\) as an input, because division by zero is undefined. For this function, we can choose a domain consisting of all real numbers except \(0\).

So a function tells us which inputs are allowed and assigns exactly one output to each of them.
