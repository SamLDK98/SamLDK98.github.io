Exponentials

From Powers to Functions

What happens to the output if we let the number of steps vary freely?

The Number of Steps as an Input

Until now, each power has had a fixed number of steps.

\[\class{mjx-base}{2}^{\class{mjx-exp}{3}} = \class{mjx-value}{8}\]

“Start at \(1\) and take \(3\) steps at a step ratio of \(2\).”

Over the first column we extended the number of steps to zero, negative numbers, fractions and finally irrational numbers.

So the number of steps can now be any real number.

This lets us treat the number of steps as an input and the value of the power as an output.

\[f(\class{mjx-exp}{x}) = \class{mjx-base}{2}^{\class{mjx-exp}{x}}\]

A function is a rule that gives exactly one output for each input.

Here the rule is: start at \(1\) and take \(x\) steps at a step ratio of \(2\).

Input \(x\)JourneyOutput \(2^x\)
\(-2\)\(1 \div 2 \div 2\)\(\frac{1}{4}\)
\(-1\)\(1 \div 2\)\(\frac{1}{2}\)
\(0\)\(1\)\(1\)
\(0.5\)\(1 \times \sqrt{2}\)\(\approx 1.414\)
\(1\)\(1 \times 2\)\(2\)
\(2\)\(1 \times 2 \times 2\)\(4\)
\(3\)\(1 \times 2 \times 2 \times 2\)\(8\)

Because the input sits in the exponent, we call this an exponential function.

Reading the Graph

Each input and its output make a point \((x, 2^x)\).

Plotting every point gives the curve in the widget above.

Notice that:

  • The curve passes through \((0, 1)\). Taking zero steps leaves us where we started.
  • Each step of \(1\) to the right doubles the height.
  • Each step of \(1\) to the left halves the height, so the curve creeps towards \(0\) but never reaches it.
  • The curve never drops below \(0\). Multiplying a positive number by a positive step ratio always gives a positive number.

The dots in the widget mark the whole-number inputs. Between them, the fractional and irrational inputs fill in the curve.

Changing the Step Ratio

The base is the step ratio, so changing it changes how much each step multiplies by.

  • A step ratio greater than \(1\) makes the output grow as we step right.
  • A step ratio of \(1\) leaves the output at \(1\) forever: every step multiplies by \(1\).
  • A step ratio between \(0\) and \(1\) makes the output shrink as we step right.

Notice that the curve for \(0.5\) is the curve for \(2\) reflected in the vertical axis.

\[\left(\frac{1}{2}\right)^{x} = \frac{1}{2^x} = 2^{-x}\]

Taking \(x\) steps at a ratio of \(\frac{1}{2}\) is the same as taking \(x\) steps backwards at a ratio of \(2\).

We only use positive step ratios.

Imagine a step ratio of \(-4\).

Whole-number steps are fine. The sign flips with each step:

\[(-4)^1 = -4 \qquad (-4)^2 = 16 \qquad (-4)^3 = -64\]

But half a step asks for the factor that, when multiplied by itself twice, gives \(-4\):

\[a \cdot a = -4\]

Any number multiplied by itself is positive (or zero), so no such factor exists among the real numbers.

The output exists at some inputs and not at the ones between them, so there is no curve to draw.

With a positive step ratio, every fraction of a step has a positive factor, so the output exists for every input.
\[\boxed{f(x) = b^{x} \qquad (b > 0)}\]

Exponential Versus Power Functions

\(2^x\) and \(x^2\) look alike, but they swap the roles of the input.

  • In \(x^2\) the input is the step ratio; the number of steps is fixed at \(2\).
  • In \(2^x\) the input is the number of steps; the step ratio is fixed at \(2\).
\(x\)\(x^2\)\(2^x\)
\(1\)\(1\)\(2\)
\(2\)\(4\)\(4\)
\(3\)\(9\)\(8\)
\(4\)\(16\)\(16\)
\(5\)\(25\)\(32\)
\(6\)\(36\)\(64\)
\(10\)\(100\)\(1{,}024\)

Increasing the input by \(1\) adds a little more to \(x^2\) each time, but it always doubles \(2^x\).

So the exponential function eventually leaves the power function far behind.

An exponential function is one whose input is the number of steps: the variable sits in the exponent.
