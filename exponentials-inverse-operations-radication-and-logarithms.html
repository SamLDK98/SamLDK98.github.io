Exponentials

Inverse Operations: Radication and Logarithms

Division and Additive Journeys

An additive journey involves adding values to reach a target output.

\[x + x + x + x + x + x + x + x = 64\]

We could add any number of \(x\) to reach \(64\) as long as we can adjust the value of \(x\) accordingly.

Likewise, we could have any value for \(x\), as long as we can adjust the number of steps accordingly.

Division can tell us either the size each step must be for a given number of steps, or vice versa.

The reason division can tell us either is because the additive journey involves multiplying two variables.

\[\class{mjx-steps}{\text{number of steps}} \times \class{mjx-size}{\text{step size}} = \class{mjx-target}{\text{target output}}\]

Say:

\[\class{mjx-size}{x} = \class{mjx-size}{\text{step size}}, \qquad \class{mjx-steps}{y} = \class{mjx-steps}{\text{number of steps}}\]

Multiplication is commutative.

If we multiply two factors \(xy\) to give an output:

  • One factor will denote the number of copies of the other factor we have.
  • The second factor will denote the value of each copy.

We could have \(a\) groups of \(b\) or \(b\) groups of \(a\).

Changing the role of the factors does not change the value of the output.

Just as taking \(16\) steps that add \(+4\) gives the same output as taking \(4\) that add \(+16\).

So:

Division can tell us the size each step must be for a given number of steps.

Division can also tell us how many steps we must take if our steps must be a certain size.

\[\frac{\class{mjx-target}{\text{target output}}}{\class{mjx-size}{\text{step size}}} = \class{mjx-steps}{\text{number of steps}}\]
\[\frac{\class{mjx-target}{\text{target output}}}{\class{mjx-steps}{\text{number of steps}}} = \class{mjx-size}{\text{step size}}\]

Radication and Logarithms for Multiplicative Journeys

A multiplicative journey involves multiplying factors to reach a target output.

\[x \cdot x \cdot x \cdot x = 64\]

Again, we have two quantities that may vary: step ratio and number of steps.

However, the relationship between these two is exponential, and exponentiation is not commutative.

\[\class{mjx-base}{2}^{\class{mjx-exp}{3}} = 8 \qquad \text{but} \qquad \class{mjx-base}{3}^{\class{mjx-exp}{2}} = 9\]
\[\class{mjx-base}{a}^{\class{mjx-exp}{b}} \neq \class{mjx-base}{b}^{\class{mjx-exp}{a}} \quad \text{in general}\]

To recover our quantities requires two different operations, depending on which one we know.

Radication: Recovering the Step Ratio

Radication identifies the necessary step ratio if we are taking a given number of multiplicative steps to reach a target output.

For example, here we know that we are taking three steps to reach \(8\), but we don't know the value the identical factors in this product must be:

\[\class{mjx-base}{x} \cdot \class{mjx-base}{x} \cdot \class{mjx-base}{x} = 8\]
\[\class{mjx-base}{x}^{\class{mjx-exp}{3}} = 8\]

We can identify the value of these factors by taking the root with the number of steps as the index and the target output as the radicand:

\[\class{mjx-base}{x} = \sqrt[\class{mjx-exp}{3}]{8}\]
\[\class{mjx-base}{x} = \class{mjx-base}{2}\]

In general, for a positive target output \(b\):

\[\class{mjx-base}{r}^{\class{mjx-exp}{n}} = b \iff \class{mjx-base}{r} = \sqrt[\class{mjx-exp}{n}]{b}\]

Logarithms: Recovering the Number of Steps

Logarithms identify the necessary number of steps to reach a target output given a step ratio.

Say:

\[\class{mjx-base}{2}^{\class{mjx-exp}{x}} = 8\]

How many multiplicative steps of \(\class{mjx-base}{\times 2}\) does it take to reach \(8\)?

We find the answer by “taking the logarithm of \(8\) to base \(\class{mjx-base}{2}\)”:

\[\class{mjx-exp}{x} = \log_{\class{mjx-base}{2}}(8) = \class{mjx-exp}{3}\]

More generally:

\[\boxed{\class{mjx-base}{a}^{\class{mjx-exp}{x}} = b \iff \class{mjx-exp}{x} = \log_{\class{mjx-base}{a}}(b)}\]

For real logarithms, \(a > 0\), \(a \neq 1\), and \(b > 0\).
